# ML 化できるポイントの設計メモ

## 現在の考え方

このプロジェクトでは、観測断面交通量を車両生成命令として直接使いません。観測値は、順方向シミュレーションのパラメータを補正する情報として使います。

最初はルールベース・単純統計で以下を推定します。

- どれくらい車を発生させるか
- どの入口から発生させるか
- 交差点でどちらへ進みやすいか
- どの方面へ向かいやすいか

## 置き換え候補 1: 発生率モデル

現在は、小領域内の観測交通量合計から地域全体の発生率を作っています。

ML 化する場合は、時間帯、道路種別、近傍観測点、曜日、天候などを特徴量にして、入口 Way ごとの発生率を推定します。

候補モデル:

- 線形回帰
- Poisson 回帰
- 勾配ブースティング
- 小規模なニューラルネットワーク

評価指標:

- 観測断面交通量の MAE
- 時間帯別の RMSE
- 入口ごとの過大・過小発生の偏り

## 置き換え候補 2: 分岐率モデル

現在は、分岐先 Way の近くにある観測交通量が大きいほど選ばれやすくしています。

ML 化する場合は、交差点ごとに「次に選ぶ Way」を確率分布として予測します。

特徴量候補:

- 進入 Way と退出 Way の角度
- 道路種別
- 車線数
- 速度制限
- 近傍観測点の交通量
- 時間帯
- 直進・右左折の分類

候補モデル:

- 多項ロジット
- LightGBM などのランキング・分類モデル
- Graph Neural Network

## 置き換え候補 3: OD 傾向モデル

現在の最小系では厳密な OD は持たず、車両は道路網上を重みに従って進みます。

次の段階では、入口と出口または方面をペアにした OD 傾向を入れます。

ML 化する場合は、観測値との差が小さくなるように OD 行列を推定します。

候補モデル:

- 重力モデル
- エントロピー最大化モデル
- 行列分解
- ベイズ推定
- 強化学習または微分可能シミュレーション

## 置き換え候補 4: 補正ループ

現在は 1 回の前処理で補正量を作ります。

次の段階では、以下の反復補正を入れます。

1. パラメータを決める
2. 順方向シミュレーションを実行する
3. 観測値との差分を計算する
4. 発生率・分岐率・OD 傾向を更新する
5. 誤差が下がるまで繰り返す

ML 化する場合は、差分からパラメータ更新量を予測するモデルを作れます。

## 優先順位

最初に ML 化すべきなのは発生率モデルです。理由は、分岐率や OD よりも入力と出力の関係が単純で、短時間・小領域でも効果を検証しやすいためです。

次に分岐率モデルを入れます。発生率が極端に外れている状態で分岐率を学習すると、分岐の問題と発生量の問題が混ざってしまうためです。

OD 傾向モデルは最後に扱います。観測断面交通量だけから OD を一意に決めることは難しく、事前分布や追加制約が必要になるためです。
