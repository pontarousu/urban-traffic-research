# forward_traffic_ml

観測交通量を補正信号として使いながら、車両を通常の順方向に流す交通シミュレーション実験です。

このサブプロジェクトは、`inverse_traffic_simulator` のように観測点需要から車両流を構成するアプローチとは異なり、車両発生、移動、分岐を先にシミュレーションし、その結果と観測交通量との差分を使ってパラメータを補正することを目指しています。

## 現在の位置づけ

このモデルはまだ作成途中です。公開版では、完成したシミュレータとしてではなく、順方向アプローチの設計方針、実装途中のコード、可視化・比較のための構成を示すものとして整理しています。

現段階では、次のような処理を実験しています。

- 対象領域の道路ネットワークを読み込む
- 車両を入口候補から発生させる
- 車両を道路リンク上で前進させる
- 交差点で分岐重みに従って次のリンクを選ぶ
- 観測点を通過した台数を集計する
- 観測交通量との差分を比較する
- 発生率、入口重み、分岐重みの補正へつなげる

## inverse_traffic_simulator との違い

| サブプロジェクト | 考え方 |
|---|---|
| `inverse_traffic_simulator` | 観測点の不足通過台数を需要として扱い、その需要を満たすように車両流を構成する |
| `forward_traffic_ml` | 車両を入口から順方向に流し、観測値との差分を使って発生率・分岐率などを補正する |

## 公開版で除外しているもの

この公開版では、実観測地点の位置情報、実交通量と位置情報を結合したデータ、生成済みの比較結果JSON/CSVを含めていません。

そのため、一部のスクリプトやビューアは、そのままでは入力データが存在せず実行できません。公開版では、順方向アプローチの設計とコード構成を示すことを目的としています。
