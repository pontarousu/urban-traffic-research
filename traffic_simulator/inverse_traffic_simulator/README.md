# inverse_traffic_simulator

観測された断面交通量を手がかりに、道路ネットワーク上の車両流を構成する逆問題型交通シミュレーションの試作です。

## 目的

観測される断面交通量を満たすような車両の流れを、道路ネットワーク上で構成することを目指しています。

通常の順方向シミュレーションでは、車両が入口から発生し、目的地や経路選択に従って移動します。一方、この試作では、観測点で必要となる通過台数を手がかりに、どのように車両を動かせば観測交通量に近づくかを検討しました。

## データについて

この公開版には、実観測地点の緯度経度、実交通量、またはそれらを結合したデータは含めていません。

実データを扱う処理のコードは、研究過程の再現性を説明するために残しています。ただし、実際に動かすには、利用規約に従って取得・管理された入力データが別途必要です。

## 非公開データと再現性について

このディレクトリには、実データを処理するためのスクリプトを含めていますが、入力データ本体は公開していません。これは、断面交通量計測地点の位置情報およびそれに由来する派生データに再配布上の制限があるためです。

研究時に使用した主な入力・中間データは次の形式です。

| パス例 | 内容 | 公開版での扱い |
|---|---|---|
| `data/TrafficVolume_Split_5min/TrafficVolume_YYYYMMDD_HHMM.csv` | 5分単位に分割された断面交通量CSV群 | 含めていません |
| `data/number_to_location.csv` | 観測地点番号と緯度経度を対応付けるCSV | 含めていません |
| `data/realdata_all.json` | 交通量CSVと観測地点位置情報を統合した中間JSON | 含めていません |
| `data/realdata_sample_small.json` | 小規模検証用に抽出したサンプルJSON | 含めていません |
| `data/current/*.json` | OSM道路網、観測点、交通量を統合した実験用シナリオ | 含めていません |
| `data/benchmarks/*.json` | 比較実験や再生用に生成したベンチマークJSON | 含めていません |

そのため、公開版の一部スクリプトは、そのままでは入力パスが存在せず実行できません。公開版では、実データそのものではなく、データをどのように変換し、どのようなアルゴリズムで車両流を構成したかを示すことを目的としています。

### 入力データ形式の概要

`TrafficVolume_YYYYMMDD_HHMM.csv` は、時刻ごとの断面交通量を持つCSVを想定しています。スクリプト内では、地点を識別する列と、5分間の交通量を表す列を読み取ります。

`number_to_location.csv` は、観測地点番号に対して緯度・経度を対応付けるCSVを想定しています。これにより、交通量データの地点番号を地理座標へ対応付けます。

`realdata_all.json` は、上記の交通量CSVと位置情報CSVを統合した中間形式です。概念的には、次のような構造を持ちます。

```json
{
  "schema_version": "1.0",
  "meta": {
    "scenario_id": "...",
    "start_time_min": 0
  },
  "graph": {
    "nodes": [],
    "ways": []
  },
  "observation_points": [
    {
      "id": "obs_xxx",
      "lat": 0.0,
      "lon": 0.0,
      "matched_way_id": "way_xxx",
      "traffic_volume": [
        {"time_min": 480, "volume_5min": 100}
      ]
    }
  ],
  "simulation_config": {}
}
```

上記は形式説明用の例であり、実際の観測地点座標や交通量データは含めていません。

## 実行方法の例

公開版には入力データを含めていないため、実データ前提のスクリプトはそのままでは実行できません。小規模なロジック確認用のデモは次のように実行します。

```bash
node src/sim_demo.mjs
```

ブラウザビューアは `viewer/index.html` から確認できます。ただし、実験用の再生JSONは公開版に含めていないため、実データの再生には別途データを用意する必要があります。

## 注意

このディレクトリは研究試作であり、完成した交通シミュレータ製品ではありません。交通信号、車線変更、渋滞波、厳密なOD推定などは今後の拡張対象です。
