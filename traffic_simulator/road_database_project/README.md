# road_database_project

交通シミュレーションで使う道路ネットワークを、トポロジーと描画形状に分けて管理するための道路DB設計プロジェクトです。

## 目的

OSM の Way をそのままシミュレーションに使うと、道路の接続関係、描画用形状、通行規制、観測点との対応が混ざりやすくなります。

このプロジェクトでは、シミュレーションで扱いやすい道路DBを作るため、道路構造を次のように分けて考えました。

- 交差点・接続関係を表すトポロジー
- 地図上の見た目を表すジオメトリ
- 単方向の移動リンク
- 交差点での進行可能方向
- 観測点や分析単位との対応

## forward_traffic_ml との関係

`road_database_project` は、`forward_traffic_ml` を進める中で必要になったサブプロジェクトです。

当初は OSM Way を直接使って順方向シミュレーションを行っていました。しかし、OSM Way をそのまま使う構成では、交差点接続、描画形状、観測点対応、分岐重みの補正を同じ構造で扱うことになり、実装と検証が複雑になりました。

そのため、道路ネットワークをトポロジーとジオメトリに分け、シミュレーションや学習で扱いやすい directed edge ベースの構造へ整理するために、この道路DB設計を作成しました。

## 公開版で除外しているもの

生成済みの大規模な GeoJSON、道路DB出力、OSM由来の加工済みデータは、サイズとデータ利用条件の観点から公開版には含めていません。

そのため、ビューアはそのままではデータを表示できません。`scripts/build_topology_prototype.py` で出力データを生成したうえで、`viewer/` から確認する構成を想定しています。

詳細な設計は [`docs/spec.md`](docs/spec.md) を参照してください。
