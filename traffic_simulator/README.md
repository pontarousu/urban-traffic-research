# traffic_simulator

公益財団法人日本道路交通情報センター（JARTIC）が公表している断面交通量データを参考に、東京都の道路ネットワーク上で交通シミュレーションを試作しています。

## 目的

車両が道路上をどのように流れるかをシミュレーションし、観測交通量に近い流れを作るための方法を検討しました。

具体的には順問題ないし逆問題的アプローチを検討しました。またそれに伴い道路ネットワークデータを整理し、今後も別のプロジェクトに利活用できる状態にすることも目的としました。

## サブプロジェクト

```text
traffic_simulator/
├── inverse_traffic_simulator/      # 逆問題的アプローチによるシミュレータの試作
├── road_database_project/        # forwardモデル拡張のために作成した道路DB設計
└── forward_traffic_ml/           # 作成途中の順方向シミュレーション実験
```

## 重要な公開方針

道路断面交通量のデータに関しては一般に公開されていますが、観測点の位置（緯度経度）のデータに関しては日本交通管理技術協会が有料で配布しているものであるため、それに関わるデータに関しては本リポジトリでも公開していません。
具体的には、実観測地点の詳細な位置情報や、それを加工したJSON/CSVを含めていません。ビューア用の生成済みJSONも、再配布制限データを含む可能性があるため除外しています。

そのため本リポジトリでは実際のシミュレータの公表よりも、どのようなアルゴリズムでシミュレータを作成したのか、またそれにはどのような成果・課題が得られたのかを書き留めることを方針としています。

## データとライセンスについて

この公開版リポジトリには、断面交通量計測地点の詳細な位置情報、およびその位置情報と交通量を結合・加工した派生データは含めていません。

断面交通量情報の数値データについては、公益財団法人日本道路交通情報センター（JARTIC）の利用規約に従い、出典表記と加工表記を行う方針です。一方で、断面交通量計測地点の位置情報および関連する派生データについては、提供元規約に基づき「2次的著作物作成計画書」を作成し、承認を待っている段階です。そのため、本リポジトリには当該位置情報およびそれに由来する再配布制限のあるデータを含めていません。

一部の実験では OpenStreetMap データを利用します。OpenStreetMap データは Open Data Commons Open Database License（ODbL）に基づいて提供されています。
