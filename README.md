# urban-traffic-research

都市道路ネットワークを対象に、到達可能性評価、道路ボトルネックの可視化、新規道路候補の評価、交通流シミュレーション、観測交通量との比較手法を試作した研究・実装プロジェクトです。

このリポジトリは公開可能なコード・設計資料・可視化結果だけを整理したものです。研究途中で使った再配布制限のあるデータや巨大な生成データは含めていません。

## 構成

```text
urban-traffic-research/
├── reachability_model/      # 道路ネットワークの到達可能性評価と道路追加候補の分析
└── traffic_simulator/       # 交通流シミュレーション、道路DB設計、観測交通量への接近実験
```

## 取り組んだこと

### 1. 到達可能性評価と道路追加候補の分析

`reachability_model/` では、OpenStreetMap 由来の道路ネットワークを使い、都市内の移動しやすさを定量化しました。

- 道路ネットワーク上の到達可能範囲の評価
- Convex Hull、メッシュ、コストラスタなど複数手法の比較
- 川や山などの地理的障害を考慮した到達可能性の可視化
- 到達効率が低い地点の抽出
- 新規道路・橋の候補を効果とコストの観点から評価

### 2. 観測交通量を用いた交通シミュレーションの作成

`traffic_simulator/` では、道路ネットワーク上で車両を動かし、観測される断面交通量に近づけるためのシミュレーション手法を試作しました。

- ブラウザを用いた交通流シミュレーションデモの可視化
- OSM道路網をシミュレーション用グラフへ変換する処理
- 道路トポロジーと描画用形状を分けた道路DB設計
- 観測交通量を使った2つのアプローチによるシミュレーションの作成
- 可視化ビューアによる道路構造・観測点対応・分岐傾向の確認

## 公開版で除外しているもの

- 再配布制限のある断面交通量計測地点の位置情報
- 実観測地点の緯度経度を含むJSON/CSV
- 実交通量と位置情報を結合した派生データ
- 大規模な生成済みシミュレーション結果
- ローカル環境専用のキャッシュや中間ファイル

## データとライセンスについて

この公開版リポジトリには、再配布制限のある交通量データ、断面交通量計測地点の詳細な位置情報、およびそれらに由来する派生データは含めていません。

断面交通量情報の数値データについては、公益財団法人日本道路交通情報センター（JARTIC）の利用規約に従い、出典表記と加工表記を行う方針です。一方で、断面交通量計測地点の位置情報および関連する派生データについては提供元規約に基づき、本リポジトリには当該位置情報およびそれに由来する再配布制限のあるデータを含めていません。

一部の実験では OpenStreetMap データを利用します。OpenStreetMap データは Open Data Commons Open Database License（ODbL）に基づいて提供されています。
